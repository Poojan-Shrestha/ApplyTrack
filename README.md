# ApplyTrack

Full-stack job application tracking system with AI-powered features.

## Tech Stack
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express + MongoDB
- AI: Google Gemini AI
- Storage: ImageKit CDN

## Local Development

### Prerequisites
- Node.js 18+
- MongoDB
- ImageKit account
- Google Gemini API key

### Setup

1. Clone repository
```bash
git clone https://github.com/Poojan-Shrestha/ApplyTrack.git
cd ApplyTrack
```

2. Backend setup
```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your credentials
npm run dev
```

3. Frontend setup
```bash
cd frontend
npm install
cp .env.example .env
# Edit .env with your credentials
npm run dev
```
